1. File Listing — ls in Depth

ls
List files and directories
Options / notes: -l long format; -a all/hidden; -h human sizes; -t sort time; -r reverse; -S size; -R recursive; -d directory itself
ls
List visible entries in the current directory.
ls -l
Long format: permissions, links, owner, group, size, modified time, name.
ls -a
Include hidden entries such as .bashrc and .ssh.
ls -la
Long format including hidden entries.
ls -lah
Long format + hidden entries + human-readable sizes such as K, M and G.
ls -lh
Long format with human-readable file sizes.
ls -lt
Sort by modification time, newest first.
ls -ltr
Long format, sort by modification time, then reverse it — oldest first and newest at the bottom.
ls -lS
Sort by file size, largest first.
ls -lSr
Sort by size in reverse, smallest first.
ls -R
Recursively list subdirectories.
ls -d */
List directories in the current directory only.
ls -ld /var/log
Show details about /var/log itself instead of listing inside it.
ls -li
Include inode numbers.
ls -ln
Show numeric UID and GID instead of owner/group names.
ls -1
One entry per output line.
ls -F
Append indicators such as / for directories and * for executables.
ls -lah /var/log
Detailed human-readable listing of /var/log.
ls -ltr /var/log | tail -20
Show the 20 most recently modified entries, with newest at the bottom.
ls -lhS /var/log | head
Show some of the largest entries in /var/log.
